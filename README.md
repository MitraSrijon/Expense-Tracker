# 💰 Expense Tracker

A modern full-stack Expense Tracker application built using **Angular 22**, **Spring Boot**, and **MySQL**.

Track your daily expenses with an intuitive dashboard, interactive charts, filtering, and responsive design.

## 🚀 Features

### Expense Management

- Add new expense
- Edit existing expense
- Delete expense
- Confirmation before deleting

### Dashboard

- Total Expenses
- Current Month Expenses
- Total Transactions
- Highest Expense

### Search & Filters

- Search by title
- Filter by category
- Filter by month
- Sort by
  - Newest
  - Oldest
  - Highest Amount
  - Lowest Amount

### Analytics

- Monthly Expense Bar Chart
- Category-wise Pie Chart

### User Experience

- Responsive UI
- Loading Spinner
- Empty State
- Modern Dark Theme

## ⚙️ Installation

### Backend

```bash
cd Backend
```

Update your MySQL credentials in

```
application.properties
```

Run

```bash
mvn spring-boot:run
```

Backend runs on

```
http://localhost:8080
```

---

### Frontend

```bash
cd Frontend
npm install
ng serve
```

Frontend runs on

```
http://localhost:4200
```
